# 📦 Logistics Data Analysis & Delivery Delay Prediction

> An end-to-end Python data analytics project exploring logistics performance, delivery delays, operational factors, costs, and predictive modeling.

---

## 🚀 Project Overview

This project analyzes an e-commerce logistics dataset containing **15,000 delivery records and 36 features**.

The project follows a complete analytics workflow — from understanding the logistics problem and preparing the data to exploratory analysis, visualization, predictive modeling, and model-informed optimization strategies.

The main objective is to understand delivery performance, identify important relationships within logistics operations, and build a machine learning model to predict **delivery delay hours**.

### 🔎 Project Flow

**Logistics Problem → Data Preparation → Exploratory Analysis → Visualization → Predictive Modeling → Evaluation → Optimization Insights**

---

## 🎯 Objectives

- Understand key logistics and delivery performance metrics
- Clean and prepare logistics data for analysis
- Explore delivery delays, costs, shipping methods, and customer satisfaction
- Identify relationships between operational variables
- Compare different machine learning regression models
- Predict delivery delay hours
- Evaluate model performance using MAE, RMSE, and R²
- Analyze feature importance
- Develop practical, model-informed logistics strategies

---

## 📊 Dataset

The project uses the **E-Commerce Logistics and Delivery Dataset** from Kaggle.

**Dataset size:**
- **15,000 records**
- **36 columns**

The dataset contains information related to:

- Order details
- Product categories
- Customer and warehouse regions
- Shipping methods
- Delivery partners
- Order value and quantity
- Package weight and volume
- Distance
- Warehouse processing time
- Traffic and weather delays
- Courier rating and experience
- Warehouse capacity utilization
- Estimated and promised delivery time
- Delivery delay
- Shipping and logistics costs
- Customer satisfaction
- Delivery status
